AJE-66 · Fasting Tracker · Mini-app revamp

From sprawling popup
to a focused mini-app.

The current Fasting popup is functional but loud — a giant fillImage ring and 90pt countdown dominate the screen, eight scroll-wheel pickers handle setup, and VerticalLayoutGroup padding hacks (top=1300, bottom=2200 → top=150, bottom=3000) try to hide it all from the viewport. This prototype rebuilds the experience as a focused mini-app with three self-contained screens — selection, active, summary — none of which need to scroll.

What changes vs your current in-app screen

Three screens, each focused on one moment in the fasting flow:

  • Selection screen — "When did you stop eating?" (Just now / Earlier today + hour slider) → preset cards (16:8 / 18:6 / 20:4 / 24h / Custom) → live preview of when the fast ends → hold-to-start with a 1-second progress fill on the button (replaces the 8-scroll-wheel start + end pickers, lines 109–201, 162–199)
  • Active fast screen — refined ring (168px, not 300px+) with phase color (amber → gold → green over the duration), soft pulse, time inside. Below: 3 info cells (Started / Plan / Ends), then Extend 1h button + swipe-to-end track (replaces the single-tap stop that risked accidental cancellation)
  • Completion summary — celebration emoji + "16h 0m fast complete", Duration + Day streak stat cards, XP-earned celebration block, "Done" / "Start another" buttons
Layout: nothing scrolls. Each screen is sized to fit a 390 × 844 viewport with safe-area padding. The current panel uses extreme VerticalLayoutGroup padding values (1300–3000 px) to push content on/off screen — that's the "scrolls off the page" problem you flagged. Mini-app structure replaces the padding hacks entirely.
Killed the 100 XP manual-end-time gate at FastingPopup.cs:632–645. With Coach's Instincts as the Max-only AI feature ([AJE-11](../paywall-revamp/)), gating the basic ability to set a custom fast length felt like friction without value. Custom is now free for everyone. Confirm with you before Abdul implements.

Annotated walkthrough

1
"When did you stop eating?" chips + Earlier-today slider
Two Buttons in a 1:1 grid. Tapping "Earlier today" reveals a child GameObject with a UnityEngine.UI.Slider (range 1–12 hours). On change, recompute start time = DateTime.Now.AddHours(-value) and update the live preview row at the bottom. Removes the four scroll wheels for start time at FastingPopup.cs:109–152 entirely.
2
Preset card carousel (16:8 / 18:6 / 20:4 / 24h / Custom)
HorizontalScrollSnap (or ScrollRect with HorizontalLayoutGroup) of 5 FastingPresetCard.prefab instances. Each card: bg Image + duration TMP_Text + tag TMP_Text + description TMP_Text. Tap to select; selected card gets the amber glow border. Replaces the four end-time scroll wheels at FastingPopup.cs:162–199. Custom reveals a single UnityEngine.UI.Slider (12–48h) — no XP gate.
3
Live preview row
TMP_Text bound to start-chip + preset-card selection. Recomputes end time on any change: endTime = startTime.Add(TimeSpan.FromHours(presetHours)). Pure derived state; no new model.
4
Hold-to-start button
Reuse the existing LongPressButton component currently driving startFastingBtn (FastingPopup.cs:225, 310). Hold duration: 1 second. The fill is now an inset Image with Type = Filled, Fill Method = Horizontal tweening from fillAmount = 0 to 1 via image.DOFillAmount(1, 1f). On complete, transition to active screen and start the existing StartCounter() flow at FastingPopup.cs:291 (PlayerPrefs save unchanged).
5
Refined ring (168px) with phase color
Replaces the existing screen-eating fillImage at FastingPopup.cs:30. Image with Type = Filled, Fill Method = Radial360, Fill Origin = Top, Clockwise = true, sized 168 × 168. Use the existing OuterRoundedFillFixed.shader for rounded caps + glow (same shader AJE-10 / AJE-65 use — visual language matches across all four screens). Color tweens between three phases: amber (0–33%), gold (33–66%), green (66–100%). Drive via DOTween.To(() => ring.color, x => ring.color = x, targetColor, 0.5f) on phase boundary cross.
6
Soft pulse on tick (heartbeat-lite)
Subtle scale pulse on the ring every 4 seconds: ring.transform.DOScale(1.02f, 0.4f).SetEase(Ease.InOutSine).SetLoops(-1, LoopType.Yoyo) with a 4-second pause between yoyos via a DOTween.Sequence. Not the full liquid-wave from SCOPE_Fasting_Screen.md — that's a bigger animation lift; the heartbeat-lite reads "alive" without overdoing it.
7
3-cell info row (Started / Plan / Ends)
HorizontalLayoutGroup with three FastingInfoCell.prefab instances. Each: label TMP_Text + value TMP_Text. Bound to the same start/duration values driving the ring. Replaces the start/end TMP_Text labels currently at FastingPopup.cs:27–28.
8
Extend 1h button
Single Button in purple — taps add 1 hour to the end time. Update PlayerPrefs.SetString("EndTime", ...), recompute total duration, animate the ring to the new fillAmount via image.DOFillAmount. Optional small toast confirmation. Maps to a future enhancement of extendFastingBtn at FastingPopup.cs:23.
9
Swipe-to-end track (replaces single-tap stop)
Replaces the bare-tap stop button at FastingPopup.cs:216–224. Drag thumb across the track to confirm. Below 80% drag distance: track resets on release. Above 80%: triggers existing StopFasting() flow + plays a small breakaway animation. Prevents fat-finger cancellation during a multi-hour fast.
10
Streak chip
Tiny pill in the top-right of the active screen showing "N-day streak". Reads from a new DataConfig.fastingStreak int (or computes locally from weeklyFastingData already fetched at FastingPopup.cs:50). Quiet visual — replaces the full BarChartFeedFasting chart that takes up vertical real estate at the bottom of the current panel. Move the bar chart to a tap-into "Stats" view rather than always-visible.
11
Completion summary
On fast completion (existing trigger at FastingPopup.cs:444–449), transition to summary screen instead of going straight back to selection. Reuse FastingCompletePopup.cs's confetti via GameManager.SpawnEffect(confettiBlue) on first show (FastingPopup.cs:405). Two-card stat grid + XP celebration block (DOPunchScale on first show). "Done" returns to home screen; "Start another" loops back to selection.

Open feasibility flags

  • Manual end-time XP gate killed — confirm with you before Abdul ships. The gate was at FastingPopup.cs:632–645; charging 100 XP just to set a non-preset end time felt like friction. With Coach's Instincts now the Max-only AI ([AJE-11](../paywall-revamp/)), this small gate looks vestigial.
  • Bar chart move — current BarChartFeedFasting is always visible at the bottom of the active screen and contributes to the overflow problem. Spec moves it into a tap-into "Stats" sub-screen accessed via a chevron from the streak chip. Confirm OK to move.
  • Active screen entry behavior — when FastingPopup.Show() is called and a fast is already active (PlayerPrefs TimerRunning=true), the spec lands directly on the active screen and skips selection. Today's behavior at FastingPopup.cs:25–73 isn't explicit about this; confirm.
  • Pulse animation density — heartbeat-lite (DOScale(1.02, 0.4f) every 4s) reads "alive" but is much subtler than SCOPE_Fasting_Screen.md's liquid-wave fill. If you want louder, we add the wave shader; if you want quieter, we drop the pulse and rely on phase color alone.
  • Notifications during a fast — out of scope here. The current panel doesn't fire phase-cross notifications ("You're in your fat-burning window now"); worth a separate ticket if product wants them.
