What changes vs your current in-app screen

The four patterns and their timings stay exactly as they are today (4-7-8, Box, Huberman, Resonant — all hardcoded in BreathworkPanel.cs:73–117). The phase state machine in RunBreathingCycle() (:385–418) and RunHubermanBreathingCycle() (:350–383) drives the same INHALE → HOLD → EXHALE rhythm.

What you'll see in the prototype that's new:

  • Soft outer glow layer around the breathing circle, sized 1.6× the inner circle and color-matched to the active phase
  • Circle scaling capped at 2.2× instead of the existing DOScale(4) at :426 — the 4× target overflows mobile viewports during testing
  • Concentric progress rings with rounded caps using the existing OuterRoundedFillFixed.shader (the same shader AJE-10's hydration ring uses)
  • Pattern-card carousel with mini line-art previews of each pattern's breathing curve — replaces the static 4-button selection
  • 3-second countdown between tapping Start and the animation beginning
  • Post-session summary screen showing cycles / minutes / pattern / avg-cycle-time / XP earned, with a celebratory pulse on the XP block
  • Inline 5-cycle XP bar with a smoother DOFillAmount tween instead of the instant fillAmount set at :364, 399
Backend dependency you should know about. The 5-cycle XP refund mechanic you called out on 2026-05-01 23:46 is net-new code. Today the panel only awards XP at the 5-cycle mark via GameManager.AddandRemoveXp(temp, "+", "Breathing Five Cycles") (:380, 415). The new mechanic is gate-deduct-then-refund: AJE-12's gate popup deducts entry XP on confirm; this panel posts a refund call at the 5-cycle mark in addition to the existing bonus award. See SPEC_breathing.md "XP economics" for the full ladder.
